# Android Messenger

Полнофункциональный мессенджер для Android с серверной частью для Windows.

## Возможности

### Клиент (Android)
- Создание групп с контактами
- Обмен текстовыми сообщениями
- Отправка и получение файлов
- Отправка и просмотр фото с предпросмотром в чате
- Голосовые сообщения
- Видеосообщения
- Интеграция с телефонной книгой
- Простой и понятный интерфейс
- Настройки:
  - IP адрес сервера
  - Порт соединения
  - Другие необходимые настройки

### Сервер (Windows)
- Рабочий интерфейс для управления
- Настройки:
  - Место хранения базы данных сообщений
  - Место хранения файлов (фото, видео, документы)
  - Конфигурация порта и других параметров

## Структура проекта

```
android-messenger/
├── app/                    # Android приложение
│   ├── src/main/
│   │   ├── java/com/messenger/app/
│   │   └── res/
│   └── build.gradle
├── build.gradle
└── settings.gradle

server/
├── server.py              # Серверная часть на Python
├── config.json            # Конфигурация сервера
└── requirements.txt       # Зависимости Python
```

## Требования

### Для Android клиента
- Android Studio Arctic Fox или новее
- Android SDK 21+
- Gradle 7.0+

### Для сервера
- Python 3.8+
- Windows 10/11
- Статический IP адрес

## Установка

### Сервер
1. Установите Python 3.8+
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте config.json
4. Запустите: `python server.py`

### Клиент
1. Откройте проект в Android Studio
2. Настройте IP адрес и порт в настройках приложения
3. Соберите и установите APK
