# Чек-лист тестирования мессенджера SecureLink

Этот документ содержит пошаговый план тестирования всех функций мессенджера перед релизом.

## 🟢 Этап 1: Подготовка окружения

- [ ] **Сервер (Windows):**
    - [ ] Запустить `build_server.bat`.
    - [ ] Убедиться, что файл `server_config.json` создан и содержит верный порт (по умолчанию 5000).
    - [ ] Проверить, что папки `data/db` и `data/files` созданы.
    - [ ] Запустить `SecureLinkServer.exe`.
    - [ ] Убедиться, что брандмауэр Windows разрешил подключение на указанном порту.
    - [ ] Проверить, что сервер слушает соединения (лог: "Server started on port...").

- [ ] **Клиент (Android):**
    - [ ] Запустить `build_client.bat` (или собрать проект в Android Studio).
    - [ ] Установить `app-debug.apk` на тестовое устройство (или эмулятор).
    - [ ] При первом запуске выдать все запрошенные разрешения:
        - [ ] Интернет
        - [ ] Контакты
        - [ ] Микрофон
        - [ ] Хранилище (Фото/Видео/Файлы)
        - [ ] Уведомления

## 🟢 Этап 2: Подключение и Настройки

- [ ] **Настройка подключения:**
    - [ ] Открыть приложение -> Меню -> Настройки.
    - [ ] Ввести IP-адрес сервера (статический IP компьютера с сервером).
    - [ ] Ввести порт (должен совпадать с настройками сервера).
    - [ ] Нажать "Сохранить".
    - [ ] Вернуться на главный экран. Статус соединения должен измениться на "Подключено" (зеленый индикатор).

- [ ] **Профиль пользователя:**
    - [ ] Зайти в Настройки -> Профиль.
    - [ ] Изменить имя пользователя.
    - [ ] Сохранить. Убедиться, что имя обновилось в интерфейсе.

## 🟢 Этап 3: Контакты и Синхронизация

- [ ] **Синхронизация:**
    - [ ] Убедиться, что в телефонной книге устройства есть контакты, у которых установлен SecureLink (или зарегистрированы на сервере с таким же номером).
    - [ ] На главном экране нажать кнопку обновления контактов (или дождаться автосинхронизации).
    - [ ] Проверить список контактов в приложении: должны отображаться только те, кто зарегистрирован на сервере.

## 🟢 Этап 4: Личные чаты (1 на 1)

- [ ] **Отправка сообщений:**
    - [ ] Выбрать контакт из списка.
    - [ ] Отправить текстовое сообщение.
    - [ ] Проверить на устройстве получателя: сообщение пришло, уведомление появилось.
    - [ ] Ответить получателю. Проверить доставку отправителю.

- [ ] **История сообщений:**
    - [ ] Закрыть приложение (свайпом убрать из фона).
    - [ ] Открыть снова, зайти в чат.
    - [ ] Убедиться, что история переписки сохранилась и загрузилась из локальной БД.

## 🟢 Этап 5: Медиа и Файлы

- [ ] **Изображения:**
    - [ ] В чате нажать кнопку "Фото".
    - [ ] Выбрать изображение из галереи.
    - [ ] Проверить предпросмотр перед отправкой.
    - [ ] Отправить.
    - [ ] У получателя проверить: картинка отобразилась в чате, можно открыть на весь экран.

- [ ] **Голосовые сообщения:**
    - [ ] Нажать и удерживать кнопку микрофона.
    - [ ] Записать сообщение (5-10 сек).
    - [ ] Отпустить (отправка) или свайпнуть (отмена).
    - [ ] У получателя проверить: плеер отобразился, воспроизведение работает, пауза/перемотка функционируют.

- [ ] **Видео:**
    - [ ] Отправить короткое видео из галереи.
    - [ ] Проверить загрузку и возможность воспроизведения у получателя.

- [ ] **Файлы:**
    - [ ] Отправить документ (PDF, DOCX и т.д.).
    - [ ] Проверить возможность скачивания и открытия файла у получателя.

## 🟢 Этап 6: Групповые чаты

- [ ] **Создание группы:**
    - [ ] Нажать кнопку "Создать группу".
    - [ ] Ввести название.
    - [ ] Выбрать 2+ контактов из списка.
    - [ ] Создать группу.

- [ ] **Общение в группе:**
    - [ ] Отправить сообщение в группу.
    - [ ] Убедиться, что сообщение получили ВСЕ участники группы.
    - [ ] Проверить отображение имени отправителя в групповом чате.

## 🟢 Этап 7: Фоновый режим и Уведомления

- [ ] **Работа в фоне:**
    - [ ] Свернуть приложение (нажать Home).
    - [ ] Проверить наличие постоянного уведомления "SecureLink running".
    - [ ] С другого устройства отправить сообщение.
    - [ ] Убедиться, что пришло Push-уведомление (текст, имя отправителя).
    - [ ] Нажать на уведомление: приложение должно открыться сразу на экране чата.

- [ ] **Экономия энергии:**
    - [ ] (Опционально) Включить жесткий режим энергосбережения на Android.
    - [ ] Убедиться, что соединение не разрывается мгновенно (благодаря Foreground Service).

## 🔴 Этап 8: Краш-тесты и Граничные случаи

- [ ] **Потеря сети:**
    - [ ] Во время чата отключить Wi-Fi/Интернет на клиенте.
    - [ ] Попробовать отправить сообщение (должна быть ошибка или статус "Ожидание").
    - [ ] Включить интернет. Сообщение должно уйти автоматически (если реализована очередь) или вручную.

- [ ] **Большие файлы:**
    - [ ] Попробовать отправить файл большого размера (например, 50 МБ).
    - [ ] Проверить стабильность соединения и целостность файла после загрузки.

- [ ] **Перезагрузка сервера:**
    - [ ] Выключить сервер во время работы клиентов.
    - [ ] Клиенты должны попытаться переподключиться.
    - [ ] Включить сервер. Клиенты должны автоматически восстановиться.
